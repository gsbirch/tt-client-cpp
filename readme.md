# Tandem Tales Client (C++)

This C++ libray provides the abstract `tt::Client` and `tt::Factory` classes
that can be extended to create [Tandem Tales](https://sgware.github.io/tt)
agents. See
[this example C++ agent](https://github.com/sgware/tt-random-agent-python)
for a demonstration of how to download and run a Tandem Tales server, define a
Python agent, connect it to the server, and play with it.

## Download and Install

If your project has a (`CMakeLists.txt`)[https://cmake.org/] file, you can add this library
to your project by adding the following lines:
```
include(FetchContent)
FetchContent_Declare(
  tt
  GIT_REPOSITORY https://github.com/gsbirch/tt-client-cpp.git
  GIT_TAG v1.0.0
)
FetchContent_MakeAvailable(tt)
target_link_libraries(*your app name* PRIVATE tt::tt)
```

## Build from Source

To download this library and build it from source:
```
git clone https://github.com/gsbirch/tt-client-cpp.git
cd tt-client-cpp
cmake -B build
cmake --build build
```

The documentation is generated by [Doxygen](https://www.doxygen.nl/). You can
regenerate it from the project root directory like this:
```
doxygen Doxyfile
```
